# SleepDiaries Protocol

This is a **template repository** for [SleepDiaries](https://github.com/circadia-bio/SleepDiaries) — an open-source, research-grade sleep diary app built with React Native and Expo, developed at Circadia Lab, Northumbria University.

You're seeing this placeholder because the repo hasn't been initialized yet. Follow the steps below to turn this into a working copy of a specific SleepDiaries release.

## 1. Initialize this repo

Go to **Actions → Initialize SleepDiaries Protocol from version → Run workflow**, pick the SleepDiaries version you want to start from, and run it.

This will replace this placeholder content with the full app source at that release, with lab-specific config (analytics, citation metadata, deployment target) already stripped out.

## 2. Set up your fork

Once the workflow finishes, a `TEMPLATE_SETUP.md` file will appear at the root of the repo with a checklist for renaming the app, swapping branding, reconfiguring deployment, and picking which questionnaires to keep.

## About SleepDiaries

SleepDiaries collects 14-day morning/evening diary entries plus 8 validated one-time sleep questionnaires (ESS, ISI, DBAS-16, MEQ, PSQI, RU-SATED, STOP-BANG, MCTQ), and ships as a cross-platform PWA. It's designed to be adapted by other researchers and clinicians running their own sleep studies.
